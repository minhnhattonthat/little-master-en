# M5 Graphics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Japanese word drawn as graphics (not text) is redrawn in English, inserted, and verified on screen.

**Architecture:** The text engine is done. M5 replaces tile graphics.
- Graphics are found with a VRAM-to-ROM matcher: dump VRAM on a screen, then match its tiles to ROM bytes.
- Art is edited as PNG and converted back to SNES planar tiles by `lmtools/gfx.py`.
- Art sitting in uncompressed ROM regions is overwritten in place.
- Art inside `EBM1` containers needs a codec (Task 3), unless the art can be moved to uncompressed space.

**Tech Stack:** Python 3.12 + Pillow (`lmtools/`, `lm.py`, pytest), Mesen2 2.1.1 headless (`tools/mesen2`), asar 1.91.

**Spec:** `docs/superpowers/specs/2026-10-05-little-master-translation-design.md`:
- M5 is "all graphic text redrawn and inserted".
- Font and display, graphic text: "the title logo, tile-drawn labels and other in-graphic text are redrawn as PNG. The title keeps the Japanese logo with an English subtitle, or gets a full English logo, depending on space."

## Global Constraints

- The base ROM is never modified. Output goes to `build/lm_en.sfc` + `build/lm_en.bps`.
- No Beta2 code, assets or text are copied. Beta2's changed regions are only a map of where graphic text lives (`data/beta2_nontext.json`).
- All art is ours: PNGs live in `src/gfx/` and are drawn for this project.
- `python lm.py lint` stays clean. `python -m pytest -q` stays green after every task.

## Review Focus

1. **A redrawn tile region that another screen also uses.** Shared tiles must still look right on every screen that draws them. Test: Task 7 sweeps every state and the title, comparing against expectations listed in `data/graphics.json`.
2. **A recompressed `EBM1` block that is larger than the original slot.** The build must either relocate it, with the pointer updated, or fail with the block's name. Test: Task 3.
3. **A PNG with a color outside the palette, or the wrong size.** `png_to_tiles` raises an error naming the file and the pixel. Test: Task 1.
4. **Palette or priority bits lost when tiles are replaced.** The tilemap is unchanged, so the colors must match the PNG preview. Test: Task 4 and Task 5 screenshot checks.
5. **A place label longer than the room on the map.** The longest English label must fit the label strip, or the build fails. Test: Task 5.

### Task 1: Graphics tooling

**Files:** Modify `lmtools/gfx.py` and `lm.py`. Create `test/lua/vram_dump.lua`. Test in `tests/test_gfx.py`.

**Interfaces (produces):**
- `gfx.encode_tiles(pixels: list[list[int]], bpp: int) -> bytes`: the inverse of `tile_planar`. `pixels` is one 8x8 tile of color indices.
- `gfx.png_to_tiles(path, bpp, palette: list[tuple[int,int,int]]) -> bytes`: tiles in left-to-right, top-to-bottom 8x8 order. Raises `ValueError(f"{path}: pixel ({x},{y}) color {rgb} not in palette")`. If the size isn't a multiple of 8, raises `ValueError(f"{path}: size {w}x{h} not a multiple of 8")`.
- `gfx.tiles_to_png(data: bytes, bpp, palette, cols, path)`.
- `gfx.cgram_palette(cgram: bytes, index: int, bpp) -> list[tuple]`: SNES BGR555 to RGB.
- `gfx.find_in_rom(rom: bytes, vram: bytes, start, end, tile_bytes) -> list[tuple[int,int,int]]`: returns (vram_addr, rom_pc, run_len) runs of matching tiles. All-zero and single-byte tiles are skipped.
- `test/lua/vram_dump.lua`: globals `STATE` (optional), `INPUTS` ({frame=key} table), `AT` (frame), `NAME`. Writes `NAME.vram`, `.cgram`, `.oam`, `.ppu`, `.png` to `OUT_DIR`.
- CLI:
  - `python lm.py vramfind <dump.vram> [--bpp 4]` prints the runs.
  - `python lm.py gfxexport --offset --count --bpp --cgram file --pal N --out x.png`.

def test_encode_tiles_inverts_tile_planar():
    import random
    random.seed(1)
    for bpp in (2, 4):
        px = [[random.randrange(1 << bpp) for _ in range(8)] for _ in range(8)]
        assert gfx.tile_planar(gfx.encode_tiles(px, bpp), bpp) == px

def test_png_round_trip(tmp_path):
    pal = [(0, 0, 0), (255, 255, 255), (255, 0, 0), (0, 0, 255)]
    data = bytes(range(64))                       # 4 tiles of 2bpp
    gfx.tiles_to_png(data, 2, pal, 2, tmp_path / "t.png")
    assert gfx.png_to_tiles(tmp_path / "t.png", 2, pal) == data

def test_png_off_palette_pixel_is_named(tmp_path):
    from PIL import Image
    im = Image.new("RGB", (8, 8), (0, 0, 0)); im.putpixel((3, 5), (1, 2, 3)); im.save(tmp_path / "bad.png")
    with pytest.raises(ValueError, match=r"bad.png: pixel \(3,5\)"):
        gfx.png_to_tiles(tmp_path / "bad.png", 2, [(0, 0, 0), (255, 255, 255)])

def test_find_in_rom_reports_runs():
    rom = bytes(100) + bytes(range(1, 97)) + bytes(50)

    assert gfx.find_in_rom(rom, vram, 0, len(vram), 32) == [(64, 100, 3)]
